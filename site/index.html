Safety is a feature

Autonomy without footguns — from first run to production CI.

01 Permission modes

ask asks before every risky action · auto auto-approves low risk, asks for dangerous · full approves everything except protected paths.

02 Protected paths

.env · ~/.ssh · ~/.aws · ~/.gnupg · ~/.config/gh — denied even in full mode.

03 Checkpoints

Every edit snapshots the file first. /undo rewinds instantly — no git needed, no branches harmed.

04 Audit receipts

Every allow/deny appended to a SHA-256 hash-chained log: .xminal/receipts/audit.jsonl · verify with xminal audit verify.

05 Secret redaction

Keys and tokens (sk-*, ghp_*, PEM blocks, JWTs…) are stripped from tool output before the model ever sees them.

06 Sandbox hooks

Optional bwrap/Docker sandbox for shell commands, plus a never-prompt safe list for read-only tools — all logged.
